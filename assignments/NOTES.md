

The Manhattan distance heuristic is admissible because it never overestimates the actual minimum cost needed to reach the goal on the grid. It calculates the minimum number of horizontal and vertical moves required, so the estimated cost is always less than or equal to the true optimal path cost.

The six test cases cover different branches of the mind-map, including typical solvable cases, boundary/trivial cases, and unsolvable or stress cases. These cases were selected to test different behaviours and edge conditions rather than using near-duplicate inputs.
